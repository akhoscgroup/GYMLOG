# GYMLOG

เว็บแอปบันทึกการออกกำลังกาย (ใช้บน iPhone ผ่าน Safari → เพิ่มไปยังหน้าจอโฮม)

- เลือกวันที่ → พิมพ์ค้นหาท่า → ใส่ น้ำหนัก / ครั้ง ต่อเซ็ต (kg / lb / เบอร์ / BW) → บันทึก
- ดูประวัติย้อนหลัง + ครั้งก่อนของแต่ละท่า
- ข้อมูลเก็บในเครื่อง (localStorage) หรือซิงก์ Supabase ได้ (ตั้งค่าในแอป — key ไม่อยู่ใน repo)
- Export JSON / CSV
